# 搜索页背景图片 / Search page Background

把你想用作搜索页背景的图片上传到这个目录，并命名为 **`background.jpg`**。

- 文件路径：`public/backgrounds/search/background.jpg`
- 网站路径：`/backgrounds/search/background.jpg`
- 推荐横向图片，1920×1080 或更大；建议压缩到 2 MB 左右。
- 上传后等待 Cloudflare Pages 部署成功，即可在对应页面看到新背景。
- 每个目录独立管理，不会影响其他页面。
- 图片会公开展示，请勿上传私人或敏感图片。

如果没有上传图片，该页面会使用网站默认底色，不影响页面正常访问。
