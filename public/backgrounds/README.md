# 书房背景图片 / Study Room Background

把你想使用的背景图片上传到这个文件夹，并将文件命名为 **`study-room.jpg`**。

- 推荐：JPG 或 WebP，横向图片，1920×1080 或更大。
- 建议文件大小控制在 2 MB 左右，避免影响页面加载速度。
- 图片上传后，网站会在下次 Cloudflare Pages 部署成功后自动使用它。
- 当前背景由仓库管理，不再通过网站页面上传或保存。
- 如需暂时不用图片背景，删除 `study-room.jpg` 即可回到 CSS 渐变背景。

GitHub 上传路径：`public/backgrounds/study-room.jpg`
网站访问路径：`/backgrounds/study-room.jpg`

注意：本文件夹里的图片会公开显示在网站上，请勿上传私人或敏感图片。
